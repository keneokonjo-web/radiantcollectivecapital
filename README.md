# Radiant Collective Capital: website concepts

Four standalone concept pages built from the Concept Playbook. Open `concepts/index.html` to compare.

| Concept | Mood | Main references |
|---|---|---|
| A Nightfall | Cinematic navy and gold | Velaa, Tengile MalaMala, Studio OL |
| B Linger | Calm, light, hospitality | Lingers |
| C Capsule | Warm editorial, giant wordmark | Mejuma Tuscany |
| D Folio | Parchment editorial, oversized intro | Studio OL, Tengile MalaMala |

All four share `concepts/data.js` (copy from rcc.africa), `common.js`, `common.css`, `fonts.css`, and the logo and photos in `concepts/img/`.
Ballena Cabo and La Caminera could not be rendered from this environment, so they are not represented.
